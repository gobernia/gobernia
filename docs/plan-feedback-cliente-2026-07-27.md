## FASE 2 — La sesión del Consejo, conectada de punta a punta

Ya tienes casi toda la maquinaria; falta la estructura fina:
- **Orden del día:** cada punto ligado a su prioridad + tarea + indicador + meta + qué decide
  el Consejo.
- **Documentos solicitados:** el sistema dice **qué subir antes de la sesión**, cada doc ligado
  a un punto, con responsable, fecha y estatus (pendiente/cargado/incompleto/validado).
- **Análisis por punto** en formato fijo: qué se esperaba / qué pasó / evidencia / desviación /
  explicación de la administración / qué decide el Consejo.
- **Acuerdos numerados** (Acuerdo 03/2026), ligados a punto + prioridad + tarea + indicador/meta
  + responsable + fecha + **evidencia esperada**.
- **Acta final** de 5 apartados: datos de la sesión / orden del día / análisis por punto /
  acuerdos / resumen estratégico.
- La regla de oro: **todo conectado** (prioridad → indicador/meta → tarea → punto → documentos →
  análisis → acuerdo → responsable/fecha/seguimiento).

## FASE 4 — El ciclo anual (roadmap 3 años ≠ plan anual)

- Los 3 años son **orientativos**; **solo el año en curso se ejecuta y se monitorea**.
- El usuario **aprueba 3–5 prioridades** antes de activar el plan (aviso si elige demasiadas).
- **Al cerrar el año**, la IA evalúa lo logrado y propone las prioridades del año siguiente
  (cerrar / mantener / subir la meta / reformular / sustituir / posponer). **No se borra el
  historial.**
